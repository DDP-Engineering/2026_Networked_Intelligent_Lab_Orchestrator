# NILO Assistant Software

This directory contains the NILO Go Bench Core and external Python
integrations. Increment 1 establishes the portable core, its version command,
and the test-routing foundation; it does not provide hardware behavior or an
MCP service.

Linux ARM64 is first and Linux x86_64 is the later appliance target. Windows
x86_64 remains a compile-only portability check rather than a NILO delivery.
