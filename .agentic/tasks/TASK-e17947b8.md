## Design

D1 (REQ-FUNC-3d711f4f): Register package adapters by manifest package id. Load checks adapter operation and artifact declarations against manifest before runner launch. Adapter hooks supply canonical parameters and dynamic resources; static manifest resources remain additive. Sigrok implements the first adapter without changing its public grammar.

D2 (REQ-FUNC-ac306a12): ProcessConfig receives a validated, immutable configure payload. Each new process completes hello and a correlated configure acknowledgement before describe or execute. A rejected or malformed response closes the process. Discovery uses plugin-only config; device-specific settings come from the core owned managed record when available.

D3 (REQ-REL-de43509b): At job persistence, extract the typed RemoteExecutionError through errors.As, map only the documented public allowlist, and keep diagnostics in bounded server storage.

D4 (REQ-DATA-8082c1dc): Match artifact ids and media types to manifest declarations at execution; preserve the existing byte and path bounds in the store. Sigrok capture remains application/octet-stream; camera image rules are deferred to its package task.

Compatibility: Existing Sigrok request and artifact contracts are the regression oracle. The real camera backend and target-specific behavior stay open in CAM-00. Test seams are manifest loader/bench fixtures, supervisor helper and Python SDK, job runner tests and browser workflow.
