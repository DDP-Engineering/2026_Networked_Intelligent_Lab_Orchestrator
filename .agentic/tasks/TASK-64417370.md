## Design

- Components: extend the repository toolchain for Windows Node.js, add `bootstrap-frontend.ps1`, add `nilo_gui`, and extend the Python test router for Windows frontend projects. [REQ-PLAT-978855a5, REQ-PLAT-e1a2a591, REQ-TEST-031b1658]
- Tool interface: `bootstrap.ps1` downloads and verifies `node-v24.20.0-win-x64.zip`; `with-tools.ps1` exposes its `node.exe` and `npm.cmd` process-locally; `doctor.ps1` verifies Node 24.20.0 and npm 11.19.0. [REQ-PLAT-978855a5]
- Restore interface: `bootstrap-frontend.ps1 [-Offline]` runs locked `npm ci` with a repository-local platform cache, and the combined development bootstrap invokes it after Windows tools and before final doctors. [REQ-PLAT-e1a2a591]
- GUI interface: `05_Software/nilo_gui` exposes `dev`, `format:check`, `lint`, `test:ci`, and `build` npm scripts; production output is ignored static `dist/` content. [REQ-PLAT-e1a2a591, REQ-TEST-031b1658]
- Dependency data: exact direct versions live in `package.json`; all transitive versions and integrity hashes live in `package-lock.json`; `node_modules`, npm cache, coverage, and dist stay ignored. [REQ-PLAT-e1a2a591]
- UI behavior: semantic header and main regions render a persistent status badge plus NILO development copy without making a backend request. [REQ-UX-188a4860]
- Repository gate: on Windows, suite discovery treats a non-generated `package.json` as a frontend suite; full runs unit tests and build, while lint runs formatting and ESLint. [REQ-TEST-031b1658]
- Rejected alternative: pnpm and SSR were rejected because an additional package-manager bootstrap and a production Node server conflict with the smallest self-contained static-appliance path. [REQ-PLAT-978855a5, REQ-PLAT-e1a2a591]
- Test seams: Python contract tests cover manifest, checksum, process-local environment, frontend restore, static project shape, and router commands; Vitest and Testing Library cover accessible simulation rendering. [all task requirements]
- Expected files: existing `02_Tools` manifest/bootstrap/env/doctor/docs and toolchain knowledge; new frontend bootstrap; `nilo_gui` source/config/lock/tests; AEGIS router/tests/config; software/development/roadmap documentation.
