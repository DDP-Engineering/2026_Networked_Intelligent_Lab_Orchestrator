## Design

Use existing authenticated HTTP client for CLI, with payloads read from file/stdin and cursor-based cancellable follow. MCP calls the same typed Core methods, reauthenticates every call, bounds reads, and authorizes log metadata before returning a relative export URL. Existing plugin tools configure/discover serial. New serial.go modules own parsers/tools; main.go/bench.go connect registration. Parent owns Core methods; compile integration waits for those contracts. No persistent client state. Failed send is never automatically replayed.
