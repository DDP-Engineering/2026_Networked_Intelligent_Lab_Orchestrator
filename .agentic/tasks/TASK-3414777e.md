## Design

D1 (REQ-FUNC-09c18b8e): The simulation catalog owns two stable camera IDs. The HTTP boundary serves a fixed-size deterministic PNG test pattern for those IDs under inventory.read only in simulation mode. This preview has no job, artifact, control state or hardware source.

D2 (REQ-UX-09873862): The catalog-created Camera navigation entry opens a camera-specific page. It selects from reported devices, fetches the authenticated preview, and labels it as generated simulation. It states that retained snapshots are not yet available. The generic integration page remains for other integrations.

Tradeoff: This is a development preview before the packaged camera runner and job workflow. It makes the interface reviewable now but does not satisfy CAM-03 through CAM-09 acceptance.
